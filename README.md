# Gowtham C — Personal Portfolio

Personal developer portfolio built with **React**, **Vite**, **Framer Motion**, and **Lucide React**.

## Features

- **Midnight Premium + Luxury Editorial** design with Dark / Light mode toggle
- Interactive **Certifications** showcase with modal certificate viewer
- Filterable **Projects** section featuring academic research and full-stack web apps
- **GitHub Repositories** integration with live GitHub REST API sync and fallback
- Accessible **Resume PDF** preview and download (`/resume.pdf`)
- Scroll-linked timeline, animated hero typography, cursor spotlight, and reduced-motion support

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment

Configured for one-click deployment on Vercel via `vercel.json`.
